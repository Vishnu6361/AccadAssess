# Supabase SQL Migrations Directory

Authoritative SQL migration files will be placed here starting with Phase 2.

Migrations naming convention:
`YYYYMMDDHHMMSS_<descriptive_name>.sql`

Phase 2 will introduce the foundational migrations:
- `01_extensions_and_enums.sql`
- `02_identity_and_academic_tables.sql`
- `03_assessment_and_rubric_tables.sql`
- `04_submission_and_evaluation_tables.sql`
- `05_processing_and_similarity_tables.sql`
- `06_audit_and_rls_policies.sql`
